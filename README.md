# 📈 FinShark (.NET Web API)

A RESTful Web API built using **ASP.NET Core**, **Entity Framework Core**, **SQL Server**, and **JWT Authentication**. This project demonstrates modern backend development concepts such as authentication, DTOs, mappers, repositories, and CRUD operations.

---

## 🚀 Features

- 🔐 User Registration & Login
- 🔑 JWT Authentication & Authorization
- 📈 Stock Management CRUD
- 💬 Comment Management CRUD
- 📝 DTO & Mapper Pattern
- 🗄️ Entity Framework Core
- 📖 Swagger API Documentation

---

## 🛠️ Tech Stack

- ASP.NET Core Web API
- C#
- Entity Framework Core
- SQL Server
- JWT Authentication
- Swagger / OpenAPI

---

## 📚 Learning Outcomes

- REST API Development
- Entity Framework Core
- JWT Security
- Repository Pattern
- DTO & Mapper Implementation
- Database Integration with SQL Server
